# 🐾 Adopt a Friend

Adopt a Friend é uma landing page desenvolvida com o objetivo de conectar pessoas a animais que precisam de um lar. O projeto foi criado como parte do meu portfólio, simulando uma plataforma de adoção de pets.

---

## 📌 Sobre o projeto

A proposta do site é facilitar o processo de adoção, permitindo que usuários encontrem animais disponíveis de forma simples, rápida e intuitiva.

---

## 🚀 Funcionalidades

* Visualização de animais disponíveis para adoção
* Interface simples e intuitiva
* Layout moderno e responsivo
* Seção de destaque para pets

---

## 🛠️ Tecnologias utilizadas

* HTML
* CSS
* JavaScript
* ( React / Tailwind )

---

## 🎯 Objetivo

Este projeto foi desenvolvido com foco em:

* Praticar desenvolvimento front-end
* Melhorar habilidades com interfaces modernas
* Criar um projeto realista para portfólio

---


---

## 💡 Inspiração

O projeto foi inspirado na importância da adoção responsável de animais e no impacto positivo que isso gera na sociedade.
